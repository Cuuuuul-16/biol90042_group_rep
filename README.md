## Overview
This project investigates Parkinson's disease (PD)
using genetic risk scores, RNA-seq analysis,
drug screening and clinical trial data.

## Analyses
1. Polygenic risk score (PRS)
2. Differential gene expression and GO analysis
3. Drug screening for neuronal viability
4. Clinical trial gait analysis
5. Linking together

## Repository Structure
- `group3_rep.qmd`: Main analysis and report
- `Figures/`: Generated figures
- `group3_data/`: Project datasets

## How to Run
Open `group_rep.qmd` in RStudio and run the code in the
document after installing the required R packages.
